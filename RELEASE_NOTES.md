# RKA Prints Android 1.2

This is the RKA Prints website in an app. It opens https://rkaprints.web.app/ and requires internet access.

- **Samsung:** works with Samsung themes; the owner confirmed version 1.1 and this release preserves its themed-icon geometry.
- **Google / Pixel:** designed to fit Google's circular icons, with a circular fallback and monochrome themed-icon support. Physical Pixel testing is pending.
- **Generic Android:** adaptive and monochrome icons for Samsung, Google and other compatible launchers; recommended if unsure.

Install one edition. All three share the same app identity and signing certificate and update the existing wrapper. Native system palette colours, native dark mode, uploads, navigation and live website loading are included.

Checks completed: compilation, APK signatures, archive integrity, version metadata, icon resources and matching certificates. Theme availability depends on Android version, launcher and theme settings. Individual Galaxy Themes icon packs may differ. The website keeps its own page styling.
